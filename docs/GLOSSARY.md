# Glossary

- **API:** A controlled way for the interface to request server work.
- **Branch:** A separate line of code changes.
- **Golden path:** The one complete journey the demo must prove.
- **MVP:** The smallest useful version.
- **Route Handler:** A Next.js server endpoint.
- **Schema:** The shape of stored data.
- **Supabase:** Hosted database and login tools.
- **Vercel:** Hosting for the Next.js app.
- **Cut line:** The point after which optional work stops.
