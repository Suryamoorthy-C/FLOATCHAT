# ARGOCHAT Hackathon OS

## Golden path
A field operator reviews ocean-device telemetry, receives a clear status or alert explanation, and records the next operational step.

## Stack
Next.js + TypeScript + Tailwind, Supabase Auth/Postgres, Vercel.

## Backend
Next.js Route Handlers for the MVP; keep provider calls server-side.

## Team lanes
- **Surface:** chat UI, empty/loading/error states, responsive polish.
- **Core:** schema, API route, prompt and response flow.
- **Glue:** setup, seed data, deployment, QA, demo coordination.

## Hard cut line
By T+180, protect the golden path. Cut translations, advanced profiles, analytics, and nonessential polish first.

## 60-second summary
ARGOCHAT is an ocean-device operations assistant. A user reviews readings from a connected ocean device, asks what an anomaly means, receives plain-language guidance, and can save the incident. The demo proves one complete telemetry-to-action journey.

## Milestones
T+30 setup; T+60 skeleton; T+120 first end-to-end flow; T+180 checkpoint; T+240 freeze; T+270 rehearsal.
